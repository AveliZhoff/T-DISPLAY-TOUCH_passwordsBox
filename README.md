# T-Display PasswordsBox

Портативный гаджет на базе **LilyGo T-Display S3** для автоматического ввода учётных данных (логинов и паролей) через USB (HID). Устройство распознаётся компьютером как обычная клавиатура.

## 📝 Описание

Устройство отображает список аккаунтов на TFT-экране. Выбор аккаунта — касанием по экрану или физическими кнопками. При нажатии кнопки гаджет имитирует набор текста: логин, `TAB`, пароль и `Enter`.

Для защиты данных при каждом запуске контроллер запрашивает **пин-код**. Неверный пин-код очищает поле ввода и повторяет запрос — доступ к паролям появляется только после разблокировки.

## 🚀 Основные возможности

- **🔒 Защита пин-кодом при запуске**
  - При каждой загрузке показывается экран блокировки: поле ввода и цифровая клавиатура `0–9` с клавишей **Enter**.
  - Цифры по мере ввода появляются в поле ввода (до 8 символов).
  - **Enter при верном пине** — разблокировка устройства, переход к списку аккаунтов.
  - **Enter при неверном пине** — поле ввода очищается, процесс ввода начинается заново.
  - Пин-код задаётся константой `PIN_CODE` в `src/credentials.h`.
  - Функционал опционален — включается/отключается `#define ENABLE_PIN_CODE`.

- **📋 Интерфейс выбора аккаунта**
  - Сенсорный экран: касание подсвечивает выбранный аккаунт.
  - Физические кнопки: **короткое нажатие** — ввод логина, `TAB`, пароля, `Enter`; **долгое нажатие** — только пароль (правая) или только логин (левая).
  - Запись с логином `nologin` вводит только пароль.

- **⌨️ USB HID клавиатура** — устройство имитирует клавиатуру через USB-C.

- **🐭 Анти-блокировка (опционально)** — автодвижение мыши каждые 60 секунд для предотвращения перехода системы в спящий режим (`#define ENABLE_MOUSE`).

- **🔆 Автоотключение подсветки** — через 30 секунд бездействия подсветка гаснет, любое касание возвращает её.

## 🛠 Аппаратное обеспечение

- **Плата:** LilyGo T-Display S3 (ESP32-S3)
- **Экран:** Встроенный TFT, 170×320 пикселей
- **Сенсор:** CST816 (емкостный тачскрин)
- **Подключение:** USB Type-C

## ⚙️ Настройка

1. **Подготовка данных:**
   - Скопируйте файл `src/credentials.example.h` в `src/credentials.h`.
   - Задайте пин-код в константе `PIN_CODE` (например, `#define PIN_CODE "8266"`).
   - Заполните массив `credentials` своими данными. Пример:
     ```cpp
     Credential credentials[] = {
       {"Name",   "your_login", "your_pass"},
       {"Mail",   "user@mail.ru", "some_pass"},
       {"PinOnly", "nologin",    "pin_only_entry"},
     };
     ```
   - Логин `nologin` означает, что для этого аккаунта вводится только пароль.

2. **Включение/отключение функций** (файл `src/T-DISPALY_passwordBox.cpp`):
   ```cpp
   #define ENABLE_PIN_CODE   // раскомментировано = запрос пин-кода при запуске
   // #define ENABLE_MOUSE    // раскомментируйте для автоматического движения мыши
   ```

3. **Сборка и прошивка:**
   - Установите [PlatformIO](https://platformio.org/).
   - Соберите проект (`pio run`) и залейте прошивку (`pio run -t upload`).
   - Настройки платы и библиотек уже указаны в `platformio.ini`.

## 🧰 Использование

1. Подключите устройство к компьютеру через USB-C.
2. На экране появится запрос пин-кода:
   - Введите цифры на сенсорной клавиатуре → они отображаются в поле ввода.
   - Нажмите **Enter** для проверки.
3. После разблокировки выберите нужный аккаунт касанием экрана.
4. Нажмите физическую кнопку:
   - **Короткое нажатие** — устройство введёт логин, нажмёт `TAB`, введёт пароль и нажмёт `Enter`.
   - **Долгое нажатие** — правой кнопкой вводится только пароль, левой — только логин.

## ⚠️ Важные замечания

- Пароли и пин-код хранятся в файле `src/credentials.h`. Обязательно сохраняйте этот файл в безопасности — он добавлен в `.gitignore` и не попадает в репозиторий.
- Пример пин-кода в `credentials.example.h` (`12345678`) — не используйте его в реальном устройстве.
- Убедитесь, что `credentials.h` создан и настроен до первой сборки.
