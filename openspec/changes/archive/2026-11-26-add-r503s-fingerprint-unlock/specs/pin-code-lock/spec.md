# Spec Delta

## MODIFIED Requirements

### Requirement: Запрос PIN-кода при запуске
Когда задан `ENABLE_PIN_CODE`, устройство SHALL при каждом запуске показывать экран ввода PIN-кода и SHALL не показывать список учётных записей до успешной аутентификации. Одновременно может быть активен только один способ разблокировки: если заданы и `ENABLE_PIN_CODE`, и `ENABLE_R503S`, прошивка SHALL использовать только разблокировку отпечатком, а PIN-код SHALL NOT компилироваться.

#### Scenario: Запуск с включённой блокировкой
- **GIVEN** сборка включает `ENABLE_PIN_CODE` и не включает `ENABLE_R503S`
- **WHEN** устройство запускается
- **THEN** оно показывает поле ввода PIN-кода и экранную цифровую клавиатуру
- **AND** список учётных записей остаётся скрытым до разблокировки

#### Scenario: Запуск с включённым только датчиком отпечатков
- **GIVEN** сборка включает `ENABLE_R503S` и не включает `ENABLE_PIN_CODE`
- **WHEN** устройство запускается
- **THEN** оно показывает экран ожидания отпечатка
- **AND** список учётных записей остаётся скрытым до разблокировки

#### Scenario: Заданы оба способа разблокировки
- **GIVEN** сборка включает `ENABLE_PIN_CODE` и `ENABLE_R503S`
- **WHEN** прошивка собирается
- **THEN** поддержка PIN-кода исключается из сборки
- **AND** при запуске показывается экран ожидания отпечатка, а PIN-экран недоступен

#### Scenario: Запуск без блокировки
- **GIVEN** сборка не включает ни `ENABLE_PIN_CODE`, ни `ENABLE_R503S`
- **WHEN** устройство запускается
- **THEN** оно сохраняет существующее поведение и сразу показывает список учётных записей
