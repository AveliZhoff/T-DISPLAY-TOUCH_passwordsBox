# Proposal

## Why

Сейчас доступ к списку учётных записей можно защитить только PIN-кодом. Добавление опциональной разблокировки по отпечатку позволит пользоваться устройством без ввода PIN, не меняя существующий сценарий и сохраняя выбор методов на этапе сборки.

## What Changes

- Добавить опциональную поддержку датчика отпечатков R503-S, включаемую макросом `ENABLE_R503S`.
- При включённом датчике блокировать список учётных записей до распознавания сохранённого в датчике отпечатка.
- Одновременно активен только один способ разблокировки: если заданы оба макроса, приоритет у отпечатка, PIN-код исключается из сборки.
- Не добавлять регистрацию отпечатков в прошивку: используются шаблоны, заранее записанные в память датчика.
- Если датчик не распознал отпечаток или недоступен, оставлять устройство заблокированным.

## Capabilities

### New Capabilities

- `fingerprint-unlock`: опциональная разблокировка устройства по сохранённому отпечатку через R503-S.

### Modified Capabilities

- `pin-code-lock`: уточнить совместное поведение PIN- и fingerprint-блокировки и доступность списка только после успешной аутентификации.

## Impact

- `src/T-DISPALY_passwordBox.cpp`: compile-time включение датчика, начальный экран блокировки и обработка результата распознавания.
- `platformio.ini`: зависимости для обмена с R503-S и конфигурация TFT_eSPI; пины UART датчика.
- `include/tft_setup.h`: конфигурация TFT_eSPI для этой платы (8-битная параллельная шина), подключается через `-DUSER_SETUP_LOADED`.
- `lib/CST816_TouchLib`: вендоренная версия 1.0.1 драйвера тача, чтобы сборка не зависела от реестра PlatformIO.
- Проводка UART датчика к LilyGo T-Display S3: TX датчика → GPIO2, RX датчика → GPIO1, питание 3.3 В (включая 3.3VT), общий GND. GPIO16/21 заняты тач-контроллером.
- Шаблоны отпечатков записываются в память R503-S отдельной прошивкой (`T-DISPLAY-TOUCH_fingerprints_R503-S`); эта прошивка их только читает.
- Основные спецификации PIN-блокировки и новая спецификация fingerprint-разблокировки.
