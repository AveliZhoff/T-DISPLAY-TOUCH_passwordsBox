# Ввод учётных данных через HID

## Purpose

Задаёт требования к отображению списка учётных записей и отправке выбранных данных через USB HID.

## Requirements

### Requirement: Отображение и выбор учётной записи
Устройство SHALL отображать имена записей из массива `credentials` на TFT-экране и SHALL позволять выбрать запись касанием экрана с визуальным выделением выбранной строки.

#### Scenario: Запуск без PIN-блокировки
- **WHEN** устройство запускается с отключённым `ENABLE_PIN_CODE`
- **THEN** оно отображает список имён учётных записей

#### Scenario: Выбор записи касанием
- **WHEN** пользователь касается строки в списке
- **THEN** устройство выделяет соответствующую запись и сохраняет её как выбранную для последующего ввода

### Requirement: Ввод логина и пароля коротким нажатием
Устройство SHALL при коротком нажатии любой физической кнопки отправлять логин выбранной записи, клавишу `TAB`, пароль и клавишу `Enter` в указанном порядке. Если логин равен `nologin`, устройство SHALL отправлять только пароль и `Enter`.

#### Scenario: Запись с логином
- **GIVEN** выбрана запись с логином, отличным от `nologin`
- **WHEN** пользователь коротко нажимает физическую кнопку
- **THEN** устройство отправляет логин, `TAB`, пароль и `Enter`

#### Scenario: Запись только с паролем
- **GIVEN** выбрана запись с логином `nologin`
- **WHEN** пользователь коротко нажимает физическую кнопку
- **THEN** устройство отправляет пароль и `Enter`, не отправляя логин и `TAB`

### Requirement: Ввод отдельных полей долгим нажатием
Устройство SHALL при долгом нажатии правой кнопки отправлять только пароль выбранной записи, а при долгом нажатии левой кнопки — только логин, если он не равен `nologin`. При этом устройство SHALL не отправлять `TAB` или `Enter`.

#### Scenario: Долгое нажатие правой кнопки
- **WHEN** пользователь долго нажимает правую кнопку
- **THEN** устройство отправляет только пароль выбранной записи

#### Scenario: Долгое нажатие левой кнопки
- **GIVEN** выбранная запись имеет логин, отличный от `nologin`
- **WHEN** пользователь долго нажимает левую кнопку
- **THEN** устройство отправляет только логин выбранной записи

#### Scenario: Долгое нажатие левой кнопки для записи только с паролем
- **GIVEN** выбранная запись имеет логин `nologin`
- **WHEN** пользователь долго нажимает левую кнопку
- **THEN** устройство не отправляет текст

### Requirement: Опциональное движение HID-мыши
Устройство SHALL, когда включён `ENABLE_MOUSE`, перемещать HID-указатель небольшими шагами в четырёх направлениях по очереди с интервалом 60 секунд.

#### Scenario: Движение мыши включено
- **GIVEN** сборка включает `ENABLE_MOUSE`
- **WHEN** проходит очередной интервал в 60 секунд
- **THEN** устройство перемещает указатель на один шаг в следующем направлении последовательности
